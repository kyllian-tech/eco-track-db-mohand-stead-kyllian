# Guide Utilisateur — Agent de Collecte

## Application Mobile Agent EcoTrack

Télécharger l'application **EcoTrack Agent** (iOS / Android / PWA)

---

## 1. Se Connecter

1. Saisir vos identifiants fournis par votre gestionnaire
2. Autoriser la géolocalisation (nécessaire pour la tournée)
3. Activer les notifications push (alertes urgentes)

---

## 2. Ma Tournée du Jour

### Consulter la tournée
1. Onglet **"Ma Tournée"** → liste des conteneurs à collecter
2. Les conteneurs sont triés par ordre de passage optimal
3. La carte affiche votre position et les conteneurs sur l'itinéraire

### Navigation vers un conteneur
1. Appuyer sur un conteneur dans la liste
2. **"Naviguer"** → ouvre l'application GPS avec l'itinéraire
3. Une fois arrivé, appuyer sur **"Arriver"**

### Marquer un conteneur comme collecté
1. Scanner le QR code sur le conteneur **ou** appuyer sur **"Collecter"**
2. L'application enregistre automatiquement l'heure et votre position
3. Le conteneur passe en vert dans la liste

---

## 3. Signaler un Problème

Si vous rencontrez un problème pendant la tournée :
1. Sélectionner le conteneur concerné
2. Appuyer sur **"Signaler un problème"**
3. Choisir le type : Conteneur endommagé / Accès bloqué / Conteneur absent
4. Prendre une photo si possible
5. Confirmer → votre gestionnaire est notifié immédiatement

---

## 4. Mode Hors-Ligne

L'application fonctionne sans connexion réseau :
- La carte et les itinéraires sont mis en cache à chaque démarrage
- Les collectes sont enregistrées localement et synchronisées quand la connexion revient
- Les données sont gardées en mémoire pendant 24h maximum

---

## 5. Fin de Tournée

1. Onglet **"Ma Tournée"** → appuyer sur **"Terminer la tournée"**
2. Un résumé s'affiche : conteneurs collectés, temps, km
3. Confirmer → le rapport est envoyé à votre gestionnaire

---

## FAQ Agent

**Je n'ai pas de tournée assignée aujourd'hui ?**  
Contactez votre gestionnaire. Les tournées sont assignées la veille avant 18h.

**La carte ne se charge pas ?**  
Vérifiez la connexion WiFi/4G. En cas de problème persistant : Menu → Actualiser les données de tournée.

**Je ne trouve pas un conteneur ?**  
Appuyer sur **"Conteneur introuvable"** dans le détail du conteneur — un signalement est créé automatiquement.
