# Guide Utilisateur — Citoyen

## Bienvenue sur EcoTrack !

EcoTrack vous permet de participer activement à la gestion des déchets de votre ville.

---

## 1. Créer un Compte

1. Télécharger l'application **EcoTrack Citoyen**
2. Appuyer sur **"S'inscrire"**
3. Saisir votre email et un mot de passe sécurisé (8 caractères minimum)
4. Valider votre email via le lien reçu
5. Vous êtes connecté !

---

## 2. Signaler un Problème

1. Ouvrir l'application et appuyer sur **"Signaler"** (icône ⚠️)
2. Sélectionner le type de problème :
   - **Débordement** — le conteneur est plein
   - **Dommage** — conteneur endommagé ou graffiti
   - **Incendie** — situation d'urgence
3. Prendre une photo du problème (optionnel)
4. Confirmer votre position GPS ou ajuster sur la carte
5. Appuyer sur **"Envoyer"**

Vous recevrez une notification quand votre signalement sera traité.

---

## 3. La Carte des Conteneurs

La carte montre en temps réel le niveau de remplissage des conteneurs proches de vous :
- **Vert** (0-50%) : conteneur disponible
- **Orange** (50-80%) : bientôt plein
- **Rouge** (80-100%) : presque plein ou signalé

---

## 4. La Gamification — Gagnez des Points !

Chaque action vous rapporte des points :
- Signalement validé → **+50 points**
- Premier signalement du mois → **Bonus ×2**
- Signalement rapide d'un conteneur plein → **+20 points**

**Débloquez des badges :**
- 🌱 **Débutant Écolo** : 1er signalement
- ♻️ **Gardien des Rues** : 10 signalements validés
- 🏆 **Champion Éco** : Top 10 du classement mensuel

---

## 5. Notifications

Activez les notifications pour :
- Recevoir une confirmation quand votre signalement est traité
- Être alerté quand un conteneur proche est plein
- Recevoir vos récompenses de points

---

## FAQ

**Mon signalement n'a pas été traité depuis 3 jours ?**  
Contactez le support via l'application : **Menu → Aide → Contacter le support**

**J'ai perdu mes points ?**  
Vérifiez dans **Mon Profil → Historique des points**

**Comment supprimer mon compte ?**  
**Menu → Paramètres → Supprimer mon compte** (conformément au RGPD, vos données seront effacées dans 30 jours)
